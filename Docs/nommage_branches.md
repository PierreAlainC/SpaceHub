# Convention de nommage des branches

Pour organiser le développement du projet, les branches suivent une convention simple selon le type de modification.

## `main`

Branche principale du projet.  
Elle contient le code stable et fonctionnel.

---

## `feature-*`

Utilisée pour développer une **nouvelle fonctionnalité**.

---

## `fix-*`

Utilisée pour corriger un bug.

---

## `refactor-*`

Utilisée pour améliorer ou nettoyer le code sans modifier le comportement.

---

## `doc-*`

Utilisée pour les modifications de documentation.

---

## `test-*`

Utilisée pour ajouter ou modifier des tests.

---

## NB:

Une fois la tâche terminée :

- fusion dans main

- push sur le dépôt distant

- suppression de la branche locale
