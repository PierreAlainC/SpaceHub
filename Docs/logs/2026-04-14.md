### FileZilla

On transfert tout le contenu du projet dans le `htdocs/` de InfinityFree avec tous ces dossiers :

```bash
htdocs/
  bin/
  config/
  public/
  src/
  templates/
  var/
  vendor/
  .env
  .htaccess
```

  et on peut laisser d côté :

```bash
.env.local
Docs/
.git/
.gitignore
tests/ (optionnel)
```

Plus de 6000 fichiers alors on attend un peu maintenant

### Prod!!!

Oublie de mettre le APP_ENV=prod

Vide le cache

On refait `composer install --no-dev --optimize-autoloader` et `php bin/console cache:clear --env=prod`

Puis upload de nouveau vendor, var et .env

### htdocs/.htaccess

```bash
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /

    RewriteCond %{REQUEST_URI} !^/public/
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^(.*)$ public/$1 [L]
</IfModule>
```
