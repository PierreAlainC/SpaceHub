## Création du ISS tracking

Commençons par mettre l'url dans le `.env.local` suivi de `services.yaml`. Pas de clé nécessaire pour les requètes de cette API.

Faisons maintenant le service nécessaire pour récupérer toutes les données possibles:

```php
<?php

namespace App\Service;

use Symfony\Component\HttpKernel\HttpKernelInterface;
use Symfony\Contracts\HttpClient\HttpClientInterface;

class IssService
{
    private HttpClientInterface $client;
    private string $apiUrl;

    public function __constrcut(HttpClientInterface $client, string $issApiUrl)
    {
        $this->client = $client;
        $this->apiUrl = $issApiUrl;
    }

    public function fetchCurrentIssPosition(): array
    {   
        // satellites/[id]
        // Returns position, velocity, and other related information about a satellite 
        // for a given point in time. 
        // [id] is required and should be the NORAD catalog id. 
        // For the ISS, that id is 25544.
        // -> https://wheretheiss.at/w/developer
        $response =$this->client->request(
            'GET',
            $this->apiUrl . 'satellites/25544'
        );

        $data = $response->toArray();

        return [
            'name' => $data['name'] ?? null,
            'id' => $data['id'] ?? null,
            'latitude' => $data['latitude'] ?? null,
            'longitude' => $data['longitude'] ?? null,
            'altitude' => $data['altitude'] ?? null,
            'velocity' => $data['velocity'] ?? null,
            'visibility' => $data['visibility'] ?? null,
            'footprint' => $data['footprint'] ?? null,
            'timestamp' => $data['timestamp'] ?? null,
            'daynum' => $data['daynum'] ?? null,
            'solar_lat' => $data['solar_lat'] ?? null,
            'solar_lon' => $data['solar_lon'] ?? null,
            'units' => $data['units'] ?? null,            
        ];
    }
}
```

Ainsi que le controlleur simplement avec `php bin/console make:controller` que l'on retouche ensuite :

```php
<?php

namespace App\Controller\Api;

use App\Service\IssService;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\Routing\Annotation\Route;
use Throwable;

/**
* @Route("api/v1/iss", name="api_iss") 
*/
class IssController extends AbstractController
{
    /**
     * @Route("", name="show", methods={"GET})
     */
    public function show(IssService $issService): JsonResponse
    {
        try {
            return $this->json($issService->fetchCurrentIssPosition());
        } catch (Throwable $e) {
            return $this->json([
                /* $e->getMessage() */ 'error' => 'Il est impossible de récupérer la position de l\'ISS pour le moment, You can\'t catch me they say!',
            ], 500);
        }
    }
}

```

## People in Space

On fait un nouvel appel via une autre Api, Open Notify, qui peut nous donner la position de l'ISS mais avec moins de détails mais surtout, nous donner les infos des astronautes étant actuellement dans l'espace!

Du coup, service, et on ajoute tout ça au controlleur de l'ISS!

On modifie le CSS, on ajoute un layout pour avoir d'un coté les données de l'ISS et de l'autre les données sur les astronautes.

Et voilà!
