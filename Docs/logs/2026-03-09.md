## Résolution problème clé API

AU dernier épisode nous étions bloqué par une erreur 401 car nous avons oublié de renter la clé API!

Déjà on commence par ajouter tout de suite notre clé `SOLAR_SYSTEM_API_KEY` a `.env.local`:

```bash
###> Service PlanetService ###
SOLAR_SYSTEM_API_KEY="**********"
```

On continue par configurer le fichier YAML `config/services.yaml`. On y ajoute le pareamètre et l'argument de notre service:

```yaml
parameters:
    # Clé stockée dans le fichier .env.local
    solar_system_api_key: '%env(SOLAR_SYSTEM_API_KEY)%'

services:    
    App\Service\PlanetService:
        arguments:
            # variable qui va stocker notre clé via le paramètre
            $solarSystemApiKey: '%solar_system_api_key%'
```

On reprend donc ensuite notre Service concerné `PlanetService` et on ajoute une nouvelle variable pour stocker la clé API et l'utiliser lors de l'appel HTTP:

```php
<?php

namespace App\Service;

use Symfony\Contracts\HttpClient\HttpClientInterface;

class PlanetService
{
    private HttpClientInterface $client;
    private string $apiKey;

    public function __construct(HttpClientInterface $client, string $solarSystemApiKey)
    {
        $this->client = $client;
        $this->apiKey = $solarSystemApiKey;
    }

    public function fetchPlanets(): array
    {
        $response = $this->client->request(
            'GET',
            'https://api.le-systeme-solaire.net/rest/bodies',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $this->apiKey,
                ],
            ]
        );

        $data = $response->toArray();

        return array_filter($data['bodies'], function ($body) {
            return isset($body['isPlanet']) && $body['isPlanet'] === true;
        });
    }
}
```

Cette méthode permet d'appeler l'API du système solaire, d'envoyer la clé d'authentification dans l'en-tête HTTP et de récupérer uniquement les objets correspondant aux planètes (isPlanet = true).
