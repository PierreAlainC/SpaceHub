## Navbar

 Mise en place d'une navbar suiple façon "breadcrumb". J'ai trouvé un moyen de faire ça bien avec template `partials` :

 ```twig
<nav class="breadcrumb">
    {% for item in items %}
        {% if not loop.last %}
            <a href="{{ item.url }}">{{ item.label }}</a>
            <span>›</span>
        {% else %}
            <span>{{ item.label }}</span>
        {% endif %}
    {% endfor %}
</nav>
```

Cela affiche la même navbar partout et il faut juste ajouter les `items` dans les templates concernés, comme par exemple ici dans `planet/show.html.twig`:

```twig
{% include 'partials/breadcrumbnavbar.html.twig' with {
                items: [
                    { label: 'Accueil', url: path('homepage') },
                    { label: 'Planètes', url: path('planets_list') },
                    { label: planet.name }
                ]
            } %}
```

Simple et efficace!
