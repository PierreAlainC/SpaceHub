## Création Service dédié à l'api Planète

On fait déjà à la main un nouveau dossier `Service` dans `src` puis le fichier `PlanetService.php` avec le `namespace` et le `use` nécessaires. 

On fait un petit `fetch` pour consommer l'api et afficher les données récupérées dans un tableau `array`.accordion

Voici:

```bash
<?php

namespace App\Service;

use Symfony\Contracts\HttpClient\HttpClientInterface;

class PlanetService
{
    private HttpClientInterface $client;

    public function __construct(HttpClientInterface $client)
    {
        $this->client = $client;
    }

    public function fetchPlanets(): array
    {
        $response = $this->client->request(
            'GET',
            'https://api.le-systeme-solaire.net/rest/bodies/'
        );

        return $response->toArray();
    }
}
```

Pour faire simple afin de vérifier les données récupérées, on va faire une méthode "test", `testApi` dans le controlleur "in charge" soit `PlanetController.php`:

On y rajoute alors:

```bash
    /**

     */
```
