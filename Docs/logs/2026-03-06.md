## Début des Fixtures Planet

On commence simple avec la commande `php bin/console make:fictures PlanetFixtures` et on obtient:

```bash
php bin/console make:fixtures PlanetFixtures

 created: src/DataFixtures/PlanetFixtures.php

           
  Success! 
           

 Next: Open your new fixtures class and start customizing it.
 Load your fixtures by running: php bin/console doctrine:fixtures:load
 Docs: https://symfony.com/doc/current/bundles/DoctrineFixturesBundle/index.htmlh

```

Ca créer le dossier `src/DataFixtures/PlanetFixtures.php` et on va faire comme suggérer on va pimper tout ça pour ensuite faire un `php bin/console doctrine:fixtures:load` ! 

Let's go dans la fonction `load()` de ce dit fichier!

On commence avec le `use App\Entity\Planet;` de notre entité à incorporer pour pouvoir l'utiliser.

Puis on rajoute manuellement les planetes à l'aide d'un array avec leur nom et slug et via une condition `foreach` on créer nos objets sans oublier un petit `persist` pour que tout rentre bien.

Ca donne:

```bash
<?php

namespace App\DataFixtures;

use App\Entity\Planet;
use Doctrine\Bundle\FixturesBundle\Fixture;
use Doctrine\Persistence\ObjectManager;

class PlanetFixtures extends Fixture
{
    public function load(ObjectManager $manager): void
    {
        // $product = new Product();
        // $manager->persist($product);
        $planets = [
            ['Mercury', 'mercury'],
            ['Venus', 'venus'],
            ['Earth', 'earth'],
            ['Mars', 'mars'],
            ['Jupiter', 'jupiter'],
            ['Saturn', 'saturn'],
            ['Uranus', 'uranus'],
            ['Neptune', 'neptune']
        ];

        foreach ($planets as [$name, $slug]) {
            $planet = new Planet();
            $planet->setName($name);
            $planet->setSlug($slug);
            $planet->setIsPlanet(true);

            $manager->persist($planet);
        }

        $manager->flush();
    }
}

```

Et voilà! Maintenant on charge tout ça dans la BDD avec `php bin/console doctrine:fixtures:load`:

```bash
php bin/console doctrine:fixtures:load

   > loading App\DataFixtures\AppFixtures
   > loading App\DataFixtures\PlanetFixtures
```

Maginifique, le nom et le slug sont en place ainsi que la date de création!
