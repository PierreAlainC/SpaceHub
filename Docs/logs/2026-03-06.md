## Début des Fixtures Planet

On commence simple avec la commande `php bin/console make:fictures PlanetFixtures` et on obtient:

```bash
php bin/console make:fixtures PlanetFixtures

 created: src/DataFixtures/PlanetFixtures.php

           
  Success! 
           

 Next: Open your new fixtures class and start customizing it.
 Load your fixtures by running: php bin/console doctrine:fixtures:load
 Docs: https://symfony.com/doc/current/bundles/DoctrineFixturesBundle/index.htmlh

```

Ca créer le dossier `src/DataFixtures/PlanetFixtures.php` et on va faire comme suggérer on va pimper tout ça pour ensuite faire un `php bin/console doctrine:fixtures:load` ! 

Let's go dans la fonction `load()` de ce dit fichier!

On commence avec le `use App\Entity\Planet;` de notre entité à incorporer pour pouvoir l'utiliser.

Puis on rajoute manuellement les planetes à l'aide d'un array avec leur nom et slug et via une condition `foreach` on créer nos objets sans oublier un petit `persist` pour que tout rentre bien.

Ca donne:

```bash
<?php

namespace App\DataFixtures;

use App\Entity\Planet;
use Doctrine\Bundle\FixturesBundle\Fixture;
use Doctrine\Persistence\ObjectManager;

class PlanetFixtures extends Fixture
{
    public function load(ObjectManager $manager): void
    {
        // $product = new Product();
        // $manager->persist($product);
        $planets = [
            ['Mercury', 'mercury'],
            ['Venus', 'venus'],
            ['Earth', 'earth'],
            ['Mars', 'mars'],
            ['Jupiter', 'jupiter'],
            ['Saturn', 'saturn'],
            ['Uranus', 'uranus'],
            ['Neptune', 'neptune']
        ];

        foreach ($planets as [$name, $slug]) {
            $planet = new Planet();
            $planet->setName($name);
            $planet->setSlug($slug);
            $planet->setIsPlanet(true);

            $manager->persist($planet);
        }

        $manager->flush();
    }
}

```

Et voilà! Maintenant on charge tout ça dans la BDD avec `php bin/console doctrine:fixtures:load`:

```bash
php bin/console doctrine:fixtures:load

 > yes

   > purging database
   > loading App\DataFixtures\AppFixtures
   > loading App\DataFixtures\PlanetFixtures
```

Maginifique, le nom et le slug sont en place ainsi que la date de création!

On a des données!!!

## PlanetControlleer

On va mettre en place le controlleur dédié à notre entité `Planet` grâce à la commande `php bin/console make:controller PlanetController`

Ce qui nous donne:

```bash
php bin/console make:controller PlanetController

 created: src/Controller/PlanetController.php
 created: templates/planet/index.html.twig

           
  Success! 
           

 Next: Open your new controller class and add some pages!
 ```

- création du dossier `src/Controller/PlanetController.php`
- création du template `templates/planet/index.html.twig`

Nous avons ce controlleur de base grâce à doctrine:

```bash
<?php

namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;

class PlanetController extends AbstractController
{
    /**
     * @Route("/planet", name="app_planet")
     */
    public function index(): Response
    {
        return $this->render('planet/index.html.twig', [
            'controller_name' => 'PlanetController',
        ]);
    }
}
```

Nous allons inclure le use pour notre Repository, modifier la route ainsi que son nom, injection du repository, modif' du passage des données à twig et nous obtenons :

```bash
<?php

namespace App\Controller;

use App\Repository\PlanetRepository;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;

class PlanetController extends AbstractController
{
    /**
     * @Route("/planets", name="planets_list")
     */
    public function index(PlanetRepository $planetRepository): Response
    {
        $planets = $planetRepository->findAll();

        return $this->render('planet/index.html.twig', [
            'planets' => $planets,
        ]);
    }
}
```
