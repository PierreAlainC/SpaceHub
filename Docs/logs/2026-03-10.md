## Affichage de toutes les données

On utilise les [données](https://api.le-systeme-solaire.net/rest/) de l'api [le-systeme-solaire](https://api.le-systeme-solaire.net/en/).

J'aurai peut être du commencer par afficher toutes les données que l'on peut récupérer avant de faire les planètes? Faisons une méthode pour cela!

On fait donc une méthode dans `PlanetService` qui fait exactement ça sans filtrer les planètes :

### Fonction

```php
    public function displayInfos(): array
    {
        $response = $this->client->request(
            'GET',
            'https://api.le-systeme-solaire.net/rest/',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $this->apiKey,
                ],
            ]
        );

        return $response->toArray();
    }
```

### Controlleur

```php
    /**
     * @Route("display-infos-api", name="display_infos_api")
     */
    public function displayInfosApi(PlanetService $planetService): Response
    {
        $data = $planetService->displayAllData();

        dd($data);
        /* return $this->render('$0.html.twig', []); */
    }
```

## Création Service dédié infos Api

Comme ce serait trop simple on va faire un Service dédié à l'affichage des infos brutes récupérées via l'Api.

Cela de manière à faire plus propre et à garder les services dédiés à un usage unique...

Nous partons donc sur le Service `SolarSystemApiService.php` avec son Controlleur attitré `SolarSystemApiController.php`

Voici une fois à jour :

```php
<?php

namespace App\Service;

use Symfony\Contracts\HttpClient\HttpClientInterface;

class SolarSystemApiService
{
    private HttpClientInterface $client;
    private string $apiKey;

    public function __construct(
        HttpClientInterface $client, string $solarSystemApiKey) 
    {
        $this->client = $client;
        $this->apiKey = $solarSystemApiKey;
    }

    public function displayInfos(): array
    {
        $response = $this->client->request(
            'GET',
            'https://api.le-systeme-solaire.net/rest/',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $this->apiKey,
                ],
            ]
        );

        return $response->toArray();
    }

        public function displayAllData(): array
    {
        $response = $this->client->request(
            'GET',
            'https://api.le-systeme-solaire.net/rest/bodies',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $this->apiKey,
                ],
            ]
        );

        return $response->toArray();
    }

    public function displayAllBodies(): array
    {
        $response = $this->client->request(
            'GET',
            'https://api.le-systeme-solaire.net/rest/bodies',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $this->apiKey,
                ],
            ]
        );

        $data = $response->toArray();

        return $data['bodies'];
    }
}
```

J'ai laissé ma curiosité aller dans la direction de l'endpoints `"/path/positions"` qui est là pour nous permettre entre de faire une carte d'observation du ciel pour un point sur terre (les objets visibles depuis en endroit particulier). On fera ça une autre fois même si çaà l'air stylé!

Pour nous éviter des répétitions sur les URLs Api appellées, on optimise ça. On fonctionne comme la clé Api stockée dans le `.env.local` avec la variable `SOLAR_SYSTEM_API_URL`. Elle est ensuite injectée dans le Service concerné et utilisée pour construire les endpoints (`/bodies`, `/positions`, etc.).

EX:

```yaml
parameters:
    # Clé stockée dans le fichier .env.local
    solar_system_api_key: '%env(SOLAR_SYSTEM_API_KEY)%'
    solar_system_api_url: '%env(SOLAR_SYSTEM_API_URL)%'


services:
    App\Service\PlanetService:
        arguments:
            # variables qui vont stocker notre clé via le paramètre
            $solarSystemApiKey: '%solar_system_api_key%'
            $solarSystemApiUrl: '%solar_system_api_url%'

    App\Service\SolarSystemApiService:
        arguments:
            # variables qui vont stocker notre clé via le paramètre
            $solarSystemApiKey: '%solar_system_api_key%'
            $solarSystemApiUrl: '%solar_system_api_url%'
```

## Note

> On pourrait faire des recherches ciblées? Selon que c'est une lune, asteroïde etc

```php
    public function fetchMoons(): array
    {
        $response = $this->client->request(
            'GET',
            $this->apiUrl . '/bodies',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $this->apiKey,
                ],
            ]
        );

        $data = $response->toArray();

        return array_filter($data['bodies'], function ($body) {
            return isset($body['bodyType']) && $body['bodyType'] === 'Moon';
        });
    }
```
