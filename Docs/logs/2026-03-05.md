## Création de l'entité ```Planet```

```bash
git pull origin main
git checkout -b feature-planet-entity
```

```bash
php bin/console make:entity Planet
```

>    /**

>    */
>   private $englishName;
>```
>
> Voila ça c'est fait.

## Migration

Facile maintenant tout est OK pour la BDD alors on utilise Doctrine une fois de plus:

```bash
php bin/console make:migration
```

puis

```bash
php bin/console doctrine:migrations:migrate
```

Et voilà ça commence à être kiffant.

>## Note:
>
>Vérification du mapping :
>
>```bash
>php bin/console doctrine:schema:validate
>```
>
>Oups petite erreur? 
>
>```bash
>php bin/console doctrine:schema:validate
>
>Mapping
>-------
>
>                                                                                                                        
> [OK] The mapping files are correct.                                                                                    
>                                                                                                                        
>
>Database
>--------
>
>                                                                                                                        
> [ERROR] The database schema is not in sync with the current mapping file.    
> ```
>
> Mauvaise adresse dans le fichier ```.env.local``` de ```DATABASE_URL="mysql://root:root@127.0.0.1:3306/spacehub?serverVersion=8&charset=utf8mb4"```
> 
>Alors modification de ```serverVersion=8``` pour ```serverVersion=mariadb-10.3.25```
> 
> On vide le cache avec ```php bin/console cache:clear``` et puis on refait une vérification et ça marche!

et j'ai ajouté manuellement les contraintes dans l'entité ```Planet```:

```bash
    /**
     * @ORM\Column(type="string", length=100, unique=true)
     */
    private $name;

    /**
     * @ORM\Column(type="string", length=120, unique=true)
     */
    private $slug;
```

Voila du coup on s'occupe des migrations et tout est bon!

Ces champs vont être d'une grande aide pour suivre la création et les mises à jour des entités, et et pour le nom et les URLs ça sera plus propre dès le début!

### Initialisation automatique de `createdAt`

Dans l’entité `Planet`, un constructeur est ajouté à la suite des propriétés et avant les getter/setter:

```bash
public function __construct()
{
    $this->createdAt = new \DateTimeImmutable();
}
```

La date de création sera automatiquement définie lors de la création d’un nouvel objet Planet.
