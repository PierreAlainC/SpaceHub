## Récupération bodyType

De manière à bien visualiser tous les éléments que nous avons à notre disposition nous avons fait une méthode nous permettant de récupérer les différents `bodyType`  :

La méthode :

```php
    public function displayBodyTypes(): array
    {
        $data = $this->displayAllBodies();
    
        $types = [];
    
        foreach ($data as $body) {
            if (isset($body['bodyType'])) {
                $types[] = $body['bodyType'];
            }
        }
    
        return array_unique($types);
    }
```

Le controlleur dans `SolarSystemApiController.php` :

De la sorte j'ai voulu faire des méthodes propres aux différents `bodyType` à savoir , `Asteroid`, `Dwarf Star`, `Comet` et `Star` de la même manière que ce que j'ai déjà pour récupérer les `Moon` :

Méthode :

```php
    public function fetchAsteroids(): array
    {
        $response = $this->client->request(
            'GET',
            $this->apiUrl . '/bodies',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $this->apiKey,
                ],
            ]
        );

        $data = $response->toArray();

        return array_filter($data['bodies'], function ($body) {
            return isset($body['bodyType']) && $body['bodyType'] === 'Asteroid';
        });
    }
```

et le Controlleur :

```php
    /**
     * @Route("display-asteroids-api", name="display_asteroids_api")
     */
    public function displayAsteroidsApi(SolarSystemApiService $solarSystemApiService): Response
    {
        $bodies = $solarSystemApiService->fetchAsteroids();

        dd($bodies);
        /* return $this->render('$0.html.twig', []); */
    }
```

Simple et efficace!
